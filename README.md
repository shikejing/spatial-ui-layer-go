# spatial-ui-layer-go

面向扩展现实（XR）的空间界面布局与交互层。界面由若干面板组成，面板挂载在三维空间中的锚点上；头显与手柄姿态持续流入，用户通过凝视射线与手柄射线选中面板。整套层在姿态持续更新、输入事件交错到达、读写并发的情况下保持一致、可复现、可解释。

## 空间模型

```
Anchor(锚点) ── Pose ──▶ Group(布局组) ── local pose ──▶ Panel(面板)
                                                          │
                                              world = anchorPose ∘ local
```

- **锚点**（`Anchor`）：面板的挂载点，三种来源——
  - `AnchorWorld`：固定于世界，`Anchor.Base` 为常量姿态；
  - `AnchorHead`：跟随头显最新已提交姿态；
  - `AnchorControllerLeft/Right`：跟随对应手柄。
- **面板**（`Panel`）：带尺寸（米）、组内顺序 `Order` 与法线层偏移 `ZOffset` 的矩形。
- **布局组**（`LayoutConfig`）：同组面板按策略在组原点周围排布，得到局部位姿；
  面板世界姿态 = 锚点姿态 ∘ 局部位姿。锚点或追踪姿态变化后，下一次 `Commit`
  只重解算受影响的面板，且同一帧内所有面板取自同一份姿态快照——
  不存在"部分新姿态、部分旧姿态"的帧。

### 布局策略

| 策略 | 说明 | 关键配置 |
|---|---|---|
| `StrategyArc` | 沿水平圆弧排布，面板面向弧心 | `Radius`、`Spacing`（弧度） |
| `StrategyGrid` | 行优先网格，整体居中，末行居中 | `Columns`、`Spacing`（米） |
| `StrategyStack` | 沿 -Z 纵深堆叠，序小者靠前 | `Spacing`（米） |

排布前按 `(Order, ID)` 稳定排序，因此**分批插入与一次性插入同一批面板
得到完全一致的结果**；集合或配置变化后整组按既定规则重排。

## 帧与提交模型

- `SubmitPose(kind, pose, ts)` 只登记姿态：时间戳不新于该源已提交样本的
  （乱序、重复）一律丢弃并返回 `false`，旧帧永远不会覆盖新姿态。
  各追踪源时间线互相独立。
- `Commit()` 划定帧边界：把当时全部已提交姿态一次性快照进新 `Frame`，
  重算 dirty 布局组与受影响面板，原子发布。帧序号单调递增。
- `Snapshot()` 返回最新帧。帧是不可变对象，经原子指针发布：
  **读方无锁、慢读不阻塞写方**，且任何时刻读到的都是自洽的单个快照。
- 只保留最新帧、每源只保留最新姿态，长时间运行内存不有界外增长。
- 单次 `Commit` 的布局重算只触及 dirty 组与姿态有变化的锚点上的面板，
  耗时与受影响范围相关，而非面板总数。

## 焦点语义

- 交互射线有两种来源：凝视（`RayGaze`）与手柄（`RayControllerLeft/Right`）。
- **遮挡感知命中**：沿射线参数 t 最近的面板获胜，被更近面板挡住的面板
  不会被选中；t 相同按面板 ID 字典序取小者，结果可复现。
- **唯一焦点**：同一时刻最多一个面板持有焦点。
- **滞留切换（抗抖动）**：新候选必须连续命中 `dwellNeed` 帧
  （`SetFocusDwell`，默认 2）才发生切换；交替抖动会不断重置候选计数，
  焦点不会来回跳变。切换时同帧有序发出 `FocusLost` → `FocusGained`。
- **显式取消**：持有焦点的面板被 `RemovePanel` 或 `RemountPanel` 时，
  返回 `FocusCanceled` 事件（而非静默丢失）；重挂载后面板按新锚点重新解算，
  可经正常滞留再次获得焦点。
- 命中与焦点推进总是基于某一已提交帧（`CastRay` 内部使用最新快照），
  焦点变化随即提交新帧对读方可见。

## 序列化

`MarshalFrame` / `UnmarshalFrame` 提供带版本号的 JSON 快照：

- 面板按 ID 升序写出，同一帧多次写出字节一致，与产生它的帧严格对应；
- 当前版本 `SnapshotVersion = 2`；读取方同时接受 v1（无 `ZOffset`/`HasFocus`
  字段，焦点仅由 `focused` 字符串表达）并自动迁移为等价 v2；
- 未知版本明确报错，不静默误读。

## 配置项一览

| 项 | 位置 | 含义 |
|---|---|---|
| `LayoutConfig.Strategy` | 布局组 | Arc / Grid / Stack |
| `LayoutConfig.Spacing` | 布局组 | 间距（Arc 为弧度，其余为米） |
| `LayoutConfig.Columns` | 布局组 | 网格列数，≤0 时取 ⌈√n⌉ |
| `LayoutConfig.Radius` | 布局组 | 弧线半径，≤0 时取 2 |
| `Panel.Order` | 面板 | 组内排布顺序（稳定排序主键） |
| `Panel.ZOffset` | 面板 | 沿法线的层偏移，参与遮挡排序 |
| `SetFocusDwell(n)` | 引擎 | 焦点切换所需连续命中帧数 |
